# JVM Basics

## What is JDK, JRE, JVM?

- **JDK (Java Development Kit):** The JDK is a software package that provides all the tools needed to develop, compile, and run Java programs. It includes the JRE, a compiler (javac), and other development tools.

- **JRE (Java Runtime Environment):** The JRE is a part of the JDK that provides the libraries, Java Virtual Machine (JVM), and other components to run Java applications. It does not include development tools like the compiler.

- **JVM (Java Virtual Machine):** The JVM is the engine that runs Java bytecode. It translates the compiled Java code (bytecode) into machine code that your computer can execute, making Java platform-independent.

## What is Bytecode?

Bytecode is an intermediate, platform-independent code generated by the Java compiler after you write and compile your Java source code. The JVM reads and executes this bytecode, allowing Java programs to run on any system with a compatible JVM.

## What does “write once, run anywhere” mean?

"Write once, run anywhere" means that you can write your Java program on one platform (like Windows) and run it on any other platform (like macOS or Linux) without changing the code. This is possible because the Java compiler generates bytecode, which the JVM can interpret and execute on any operating system that has a compatible JVM implementation. This makes Java highly portable and convenient for cross-platform development.
