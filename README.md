# Student and Course Management System

## Project Description
This is a simple Java console application for managing students, courses, and enrollments. It allows you to add, view, search, and deactivate students; add, view, and activate/deactivate courses; and enroll students in courses, view enrollments, and update enrollment status. The application demonstrates OOP concepts, exception handling, and menu-driven user interaction.

## How to Compile and Run

1. **Open a terminal in the project root directory.**
2. **Compile all Java files:**
   ```sh
   javac com/airtribe/learntrack/entity/*.java com/airtribe/learntrack/service/*.java com/airtribe/learntrack/exception/*.java com/airtribe/learntrack/ui/Main.java
   ```
3. **Run the application:**
   ```sh
   java com.airtribe.learntrack.ui.Main
   ```

- Ensure you have JDK 17 or later installed.
- All data is stored in memory (no database required).
